# 更新日志

## [v1.2.0] - 2025-11-14

### 🚀 重大改进：纯HTML元素用户昵称获取方法

#### 核心改进
- **完全重构用户昵称识别逻辑**：从依赖文本过滤改为基于精确HTML元素样式特征
- **消除系统消息误识别**：不再将"你撤回了一条信息"等系统消息误识别为用户昵称
- **提高识别准确性**：只识别真正的用户昵称元素，避免误识别

#### 技术细节
**旧方法（已移除）**:
- 依赖复杂的文本内容过滤算法
- 需要维护系统消息关键词列表
- 容易误识别新出现的系统消息类型

**新方法（纯HTML元素）**:
- 基于精确的HTML样式特征识别用户
- 核心选择器：
  ```javascript
  // 真正的用户昵称元素特征
  'div[style*="max-width: 176px"][style*="font-weight: 500"][style*="color: rgb(51, 51, 51)"]'
  'div[style*="overflow: hidden"][style*="text-overflow: ellipsis"][style*="white-space: nowrap"][style*="max-width: 176px"]'
  ```
- 不依赖任何文本内容过滤

#### 影响的功能
- ✅ `merged_get_chat_list_users.py` - 用户列表获取工具
- ✅ `optimized_batch_crawler.py` - 优化版批量爬取工具
- ✅ `start_menu.py` - 主程序菜单选项4
- ✅ 所有相关的批量爬取功能

#### 测试验证
- 创建了专门的测试文件验证改进效果
- 测试结果显示用户昵称获取准确性显著提高
- 成功避免了系统消息的误识别

### 🛠️ 新增工具
